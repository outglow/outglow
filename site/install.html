Install, update or restore firmware

The first installation uses Bluetooth. After pairing with your hub, you can configure Zigbee2MQTT to offer future releases. Updates start when you choose to install them.

Outglow is experimental. Most hardware variants have only been checked in an emulator; the compatibility list distinguishes a known hardware match from a physical test.

Before you start

  • A bulb whose module and hardware revision match an Outglow build. The firmware tool checks this after connecting.
  • A browser with Web Bluetooth support, such as Chrome or Edge on a supported computer or Android device. Support depends on the browser and operating system; the firmware tool checks availability before connecting. Browser compatibility.
  • Zigbee2MQTT. The guide below uses Zigbee2MQTT. Outglow offers standard Zigbee light controls, but support for its extra settings and updates depends on your hub.

1. Install over Bluetooth

  1. Keep the bulb powered throughout the update. Close the vendor app so it does not hold a Bluetooth connection.
  2. Switch the bulb off and on. On the tested original firmware when unpaired from the vendor app, Bluetooth accepts connections for about 20 minutes after power-on (an update already running is not cut off when that time is up).
  3. Open the flasher on a device within a few metres of the bulb.
  4. Click Connect to a bulb and pick it from the list. The flasher reads its model and proposes the matching Outglow release.
  5. Tick the confirmation and click Start the update. Allow several minutes. Keep the bulb powered, the page open and your device awake until the tool reports completion.
  6. When the transfer completes, allow the bulb to restart. If it is still dark after a minute, switch it off and on. A completed transfer is not confirmation that the new firmware has booted.

2. Add it to Zigbee2MQTT

  1. Click Permit join in Zigbee2MQTT. The bulb starts looking for a network as soon as it restarts.
  2. Not there after a few minutes? Reset it and permit joining again.
  3. The bulb shows up as outglow-dimm, outglow-tw or similar. If it was already in Zigbee2MQTT before, ask Zigbee2MQTT to interview it again. An interview reads the bulb’s identity and available controls; check that it now appears as Outglow.
  4. Optional: for all the diagnostics, the start-up brightness and the motion sensing switch, add the Outglow converter. Without it Zigbee2MQTT still shows the light, the router's main values and the settings.

3. Get updates

Add the Outglow update list to Zigbee2MQTT's configuration.yaml:

ota:
  zigbee_ota_override_index_location: https://outglow.github.io/ota/index.json

Outglow periodically asks the hub about updates, normally once a day. With automatic update checks enabled, Zigbee2MQTT can mark a matching release as available. Installation starts when requested, or when an update you scheduled becomes due. Zigbee2MQTT update controls.

The Zigbee2MQTT converter (optional)

A converter is a device definition that gives Zigbee2MQTT names and controls for Outglow’s extra features. The file outglow.mjs adds controls and names for the router diagnostics grouped by topic, the start-up brightness, and the motion sensing switch and settings. It applies only to bulbs running Outglow. Use a current Zigbee2MQTT 2.x release; from version 2.11, allow external converters first in configuration.yaml:

advanced:
  enable_external_js: true

After enabling external converters if required, restart Zigbee2MQTT. Then choose one installation method below.

Install from a terminal

Command-line method (needs curl, jq and mosquitto_pub; add -u/-P if your broker has a password, and change zigbee2mqtt if you use another base topic):

curl -fsSL https://outglow.github.io/z2m/outglow.mjs \
  | jq -Rs '{name: "outglow.mjs", code: .}' \
  | mosquitto_pub -h YOUR_BROKER -t zigbee2mqtt/bridge/request/converter/save -s

Zigbee2MQTT saves it in its external_converters folder and loads it. To check: mosquitto_sub -h YOUR_BROKER -t zigbee2mqtt/bridge/converters -C 1 lists outglow.mjs. To remove it, send {"name": "outglow.mjs"} to zigbee2mqtt/bridge/request/converter/remove.

Using the Zigbee2MQTT web interface: in the Zigbee2MQTT frontend, open Settings → Dev console → External converters, add one named outglow.mjs and paste the file's contents.

By hand: put the file in the external_converters folder next to Zigbee2MQTT's configuration.yaml (Docker: ./data/external_converters/, a Linux install: /opt/zigbee2mqtt/data/external_converters/) and restart Zigbee2MQTT.

A bulb that was already in Zigbee2MQTT picks the converter up after Zigbee2MQTT restarts or after you interview it again. More in Zigbee2MQTT's guide to external converters.

Motion sensing (experimental)

Outglow bulbs can notice people moving through a room from how the radio signal between them changes, and report it as occupancy, like a motion sensor. Standard Outglow builds include it, switched off: until you switch it on, the bulb sends nothing extra. It has been tested in the emulator only. Reliable room occupancy detection has not been established on hardware. How it works.

  1. With the converter installed, switch Motion sensing on in at least two bulbs in the same room. Each bulb senses along the links to the others, so a bulb on its own sees nothing.
  2. Let it calibrate itself: a day after you switch it on, each radio path can use its quietest recorded hour, provided enough usable samples were collected. Or calibrate by hand once the bulbs have been powered for at least a minute and are receiving each other’s measurements: leave the room empty and still, choose start under Calibrate motion sensing on each bulb, and wait a minute.
  3. Too many false alarms? Lower Motion sensitivity, or calibrate again with the room empty. Setting the sensitivity by hand switches the automatic calibration off.

Use the converter for named motion controls. It avoids entering low-level Zigbee setting numbers by hand.

Factory reset

A bulb has no button, so the reset is a pattern of switching it on and off at the wall: three short power-ons, two long ones, then on again. Outglow follows the reset pattern of the tested original firmware. It removes the bulb from its Zigbee network and turns Bluetooth back on.

  1. Switch on for about 1 second, then off. Do this three times.
  2. Switch on for about 12 seconds, then off. Do this twice.
  3. Switch on and leave it on. The bulb blinks three times when the reset worked.

Leave it off for about 6 seconds each time. A short power-on must stay under 6 seconds, a long one between 6 and 30. Got it wrong? Leave the bulb on for half a minute and start again.

Going back to the original firmware

Use the same flasher: connect to the bulb and choose Original firmware, then review and start the update. When a matching original file is available, the tool downloads it and checks its compatibility before transferring it. If the option is unavailable, this site does not currently have a matching original file. You may need to pair the bulb again after restoring it.

If you switched Bluetooth off in Outglow, switch it back on in Zigbee2MQTT first. A reset turns it back on too, but also removes the bulb from your network.
