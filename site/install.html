Install

The first install goes over Bluetooth from the original firmware. After that, updates come over Zigbee.

Before you start Outglow is experimental and has run on one real bulb so far. A failed or wrong update can leave a sealed bulb without a way back. Try it on one bulb you can spare first.

You need

  • A bulb on its original firmware, from the list of boards.
  • Chrome or Edge with Web Bluetooth: on a desktop (Windows, macOS, Linux, ChromeOS) or on Android. Safari and every browser on iPhone and iPad have no Web Bluetooth.
  • The image for exactly that board and hardware revision (the flasher checks this).
  • For the Zigbee part: Zigbee2MQTT (other coordinators work for joining; the diagnostics converter and the OTA index are for Zigbee2MQTT).

1. Flash over Bluetooth

  1. Switch the bulb off and on. The original firmware accepts Bluetooth connections for about 20 minutes after power-on; a transfer already running is not cut off when that time is up.
  2. Stay close to the bulb (a few metres) and open the flasher.
  3. Choose the image: a release from the list, or an …-ota.bin file you built. A Zigbee .ota file is not what goes over Bluetooth.
  4. Connect and pick the bulb. The flasher reads its model and hardware revision and refuses an image for another board.
  5. Start. Erasing takes a few seconds, the transfer about four minutes. Keep the page open and the computer awake.
  6. When it reports success the bulb restarts by itself and installs the image. If it stays dark for more than a minute, switch it off and on.

2. Join the Zigbee network

  1. Permit joining in Zigbee2MQTT. The bulb looks for a network after the restart.
  2. If it does not join within a few minutes, factory-reset it with the same power-cycle sequence as the original firmware.
  3. Outglow reports itself as open-eglo-dimm, open-eglo-tw and so on. A bulb that was already in Zigbee2MQTT is interviewed again.
  4. For the diagnostics and the Bluetooth settings, add the external converter z2m/open-eglo.mjs to Zigbee2MQTT.

3. Updates over Zigbee

Point Zigbee2MQTT at the Outglow OTA index:

ota:
  zigbee_ota_override_index_location: https://outglow.github.io/outglow/ota/index.json

The bulb asks for a new image 30 seconds after it starts and then once a day. Zigbee2MQTT then shows the update as available; it installs it when you press Update (or when you scheduled it, or an automation asks for it). Details: ota/README.md.

Going back to the original firmware

Outglow keeps the Bluetooth update channel of the original firmware, so the way back is the way in: put the original image for the board on the bulb with the flasher. The original images are not distributed here; the script tools/extract-stock-images.sh takes them out of the vendor's Android app on your own machine. The original firmware can also be wrapped as a Zigbee OTA file under Outglow's image type and sent from Zigbee2MQTT.

Not yet tried on hardware Both ways back work in the emulator against the real images but have not been done on a real bulb yet. If you switched Bluetooth off in Outglow, only the Zigbee way is left until a power-cycle window or a factory reset brings Bluetooth back.
