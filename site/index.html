More control over your Zigbee bulbs

Outglow replaces the firmware in compatible EGLO connect.z and AwoX bulbs. It adds updates through your Zigbee hub, network diagnostics and control over when Bluetooth runs. Installation uses Bluetooth, without opening the bulb.

What changes

See why a bulb loses contact

Outglow reports nearby routers, failed deliveries, retries and restarts. Read them in Zigbee2MQTT or connect directly with the Bluetooth console. The original firmware does not offer this diagnostics service.

Update from your hub

The original firmware uses Bluetooth for updates. Outglow also accepts updates over Zigbee. Add its update list to Zigbee2MQTT, then choose when to install a release.

Choose when Bluetooth is available

Keep it on for the vendor app, allow it briefly after power-on, or turn it off. Zigbee and Bluetooth share one radio; limiting Bluetooth leaves more time to listen for Zigbee messages.

Differences you can see in the tests

In the tested original firmware, a fade-to-off can leave the bulb glowing at its lowest brightness. A repeated group toggle can run twice. A router that has gone silent can remain listed as reachable. Outglow handles these cases as expected in the same emulator tests.

The comparison explains each situation, what both firmwares did and what a failure could mean in use. These are controlled software tests; they do not promise that every network problem will disappear after installing Outglow.

What stays familiar

The bulb still supports Zigbee light controls and the vendor app's Bluetooth controls. Outglow reproduces the original brightness and colour curves and the wall-switch reset sequence, checked in the emulator. It identifies itself to your hub as Outglow, so the hub needs to discover its features again.

You can restore the original firmware when a matching file is available. The vendor's startup and update program stays in place. You may need to pair the bulb again after changing firmware.

Where the project stands

Outglow is an experimental, open-source project. The documented hardware testing is on a dimmable filament bulb; most supported hardware variants and protocol behaviours have been tested only in the emulator. It is not Zigbee or Bluetooth certified.

Firmware builds cover 21 combinations of module and hardware revision. A product name alone is not enough to choose a build: manufacturers sometimes change the electronics inside the same product. Check the compatibility list, then let the firmware tool read your bulb's identity.

Experimental motion sensing uses changes in the radio signal between bulbs. It is off by default and has not yet been validated on real bulbs.

Install when you are ready

Read the guide, connect to the bulb over Bluetooth and check the proposed firmware before starting. Later updates can use Zigbee2MQTT. You choose when to install them.
