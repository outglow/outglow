Open firmware for sealed smart bulbs

Outglow replaces the closed firmware of Zigbee bulbs built on the Telink TLSR8258 with an open one: a Zigbee router written in Rust that you can read, test and change. It goes on over Bluetooth, straight from the original firmware, so the bulb never has to be opened.

How to install Open the flasher Source code
Experimental. Outglow runs on one real bulb (a dimmable filament bulb, ESMLFzm_w6_Dimm 4.63) in a home network. Every other board below is built and tested in an emulator of the chip against that board's original firmware, but has not run on real hardware yet. Flashing firmware can leave a bulb unusable; do it only if you accept that risk.

What it does

A Zigbee router in Rust

Its own Zigbee PRO stack, without allocation or unsafe: network security, mesh routing, children for end devices, groups, scenes, colour, OTA updates with resume, touchlink and a Green Power proxy. Not certified by the Connectivity Standards Alliance.

Bluetooth stays

The bulb keeps the Bluetooth profile of the original firmware, so the vendor app still controls it and the same Bluetooth update path takes you back. From Zigbee you can switch Bluetooth off or limit it to a window after power-on.

Light as before

Brightness curves, colour and power-on behaviour are taken from each board's original firmware and compared with it level by level in the emulator.

A router you can see into

Diagnostics over Zigbee: counters, neighbours and link costs, noise floor, stack depth and a black box of the last frames sent. A Zigbee2MQTT converter shows them.

Tested before it ships

Hundreds of host tests and scenarios in an emulator of the TLSR8258 that runs the real firmware images, including the original firmware side by side, so anyone can check a change between bulbs before flashing it.

Free software

GPL-3.0-or-later: whoever ships Outglow on a device must give you the source and a way to install your own version.

Supported bulbs

Bulbs with the Telink TLSR8258 module and the AwoX Bluetooth profile, sold under the EGLO Connect.Z name among others. The board is the model and hardware revision the bulb reports over Bluetooth; each needs its own image.

How it gets onto a bulb

  1. First time, over Bluetooth. The original firmware accepts a firmware update over Bluetooth without a password. The browser flasher sends the Outglow image the same way the vendor app sends updates.
  2. Then over Zigbee. Outglow is an ordinary Zigbee OTA client: Zigbee2MQTT can offer it new versions from the Outglow OTA index.
  3. Back to the original. The original firmware goes back by the same Bluetooth path (or by Zigbee OTA).
