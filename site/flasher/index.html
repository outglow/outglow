Install or restore firmware

Connect to read the bulb’s identity and see which firmware is available. Connecting does not install anything; the update begins only after you select a file and confirm. Read the install guide before your first update.

This browser has no Web Bluetooth. Try Chrome or Edge on a computer or Android device with Web Bluetooth support. Availability also depends on the operating system.

3. Update

    Advanced options

    Only if an update is refused without it. A bulb paired to the vendor app has its own network name and password. A new bulb is usually named "unpaired"; its password can be derived from its Bluetooth address, the first six byte pairs of the permanent Zigbee address shown by your hub. This field expects encoded bytes, not an ordinary text password.

    Block size is the amount of firmware sent in each write. Larger blocks require a larger Bluetooth message limit, which the browser negotiates without exposing its value. The tested original firmware accepts up to 240 bytes and Outglow up to 57 bytes. Keep the default unless you are troubleshooting transfer speed.

    Another hardware revision may wire the light differently. The bulb could stay dark or fail to start; recovery may require a working wireless connection that you no longer have. Type I accept to go on.
