Supported bulbs

Find bulbs whose internal hardware matches an Outglow build. A confirmed product match means we know which module a reported example contains; it does not mean Outglow has been tested on that exact product.

Check the module and hardware revision. The same product has shipped with different modules, and a vendor update can change its reported module name. The flasher reads the module name and hardware revision from the bulb and checks them against the firmware. Use this list to identify candidates, then connect to confirm the match before installing.

Two different kinds of confidence

Product matching tells us which electronics are inside a lamp. Hardware testing tells us whether Outglow has actually run on that module. Each card shows both. Other variants have firmware builds and emulator checks, but no recorded test on a physical bulb.

Product-to-module match

  • confirmed a bulb with that article number was seen reporting this module (in Zigbee2MQTT reports, its device database, or on a bulb we own).
  • likely the same product family and light as a confirmed one, but the module has not been confirmed for that product.
  • inferred only the module name points to it (for example c5_E14: 5 W colour, E14 socket). Treat it as a guess until the flasher confirms it.
